# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Human Risk Graph, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

### How to Report

Send a report to: **contact@alekseialeinikov.com**

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

### Response Timeline

- **Acknowledgement**: within 48 hours
- **Assessment**: within 7 days
- **Fix release**: within 30 days for confirmed vulnerabilities

### Scope

This policy applies to the `human-risk-graph` Python package and its source code in this repository.
