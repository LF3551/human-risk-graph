# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who takes part in issues, pull requests and discussions is
expected to follow it.

Report unacceptable behaviour to **contact@alekseialeinikov.com**. Reports are handled
confidentially by the maintainer.
